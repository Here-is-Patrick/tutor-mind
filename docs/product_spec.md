# TutorMind 产品规格说明书 (Product Spec)

## 1. 产品概述

TutorMind 是一个基于多智能体协作的「一对一学习辅导 Agent」系统。通过 LangGraph 状态机编排和 CrewAI 多智能体协作，系统能够：

- 收集并维护学生个人信息和学习画像
- 在知识库中检索相似历史问题，复用教学路径
- 采用苏格拉底式提问法引导学生自行推导答案
- 知识库未命中时，调用 Tavily Search API 实时检索生成回答
- 根据学生基础水平自适应调整教学风格和语言难度

## 2. 目标用户

| 用户群体 | 典型场景 |
|---------|---------|
| 中小学生 | 课后作业辅导、知识点答疑 |
| 大学生 | 课程概念理解、考前复习 |
| 考研/考证人群 | 重点知识讲解、习题辅导 |
| 自学者 | 系统性知识学习、问题解答 |

## 3. 用户故事

### US-1：新学生首次提问
> 作为一名学生，我希望系统在我首次提问时能够引导我提供基本信息（年龄、学历、基础水平），以便获得适合我的辅导。

**验收标准**：
- 新学生发送第一条消息后，系统识别信息缺失并礼貌追问
- 学生回复个人信息后，系统提取并保存到 SQLite
- 信息完整后进入正常问答流程

### US-2：老学生重复提问相似问题
> 作为一名学生，当我问与之前类似的问题时，系统不应直接给我答案，而应通过提问引导我自行推导。

**验收标准**：
- 系统在知识库中检索到相似问题（cosine_similarity > 0.75）
- 系统切换为苏格拉底教学 Agent，发出引导提问
- 学生每回答一步，系统给出下一步引导
- 学生最终自行推导出答案

### US-3：学生提出全新问题
> 作为一名学生，当我提出知识库中没有的问题时，系统应通过网络搜索提供准确回答。

**验收标准**：
- 知识库未命中（相似度 < 0.75）
- 调用 Tavily Search API 实时搜索
- 从搜索结果提取相关信息生成结构化回答
- 将新的问答对保存到知识库供后续复用

### US-4：基础薄弱学生的自适应教学
> 作为一名基础薄弱的学生，我希望系统用通俗易懂的语言解释概念，将复杂内容拆解为小步骤。

**验收标准**：
- `is_weak_foundation = True` 时，回答使用日常例子和类比
- 专业术语附带解释
- 苏格拉底提问步长更小

### US-5：查看学习报告
> 作为一名学生，我希望查看我的学习报告，了解提问统计和常见主题。

**验收标准**：
- 提供总问题数、引导次数、搜索次数
- 列出常见学习主题
- 显示基础水平标记

## 4. 功能列表与优先级

| 优先级 | 功能 | 描述 |
|-------|------|------|
| P0 | 学生信息收集 | 自动检测缺失信息并礼貌追问 |
| P0 | 知识库优先检索 | 向量检索历史问答 Top-3 |
| P0 | 苏格拉底式引导 | 递进式提问引导学生推导 |
| P0 | Tavily 实时搜索 | 知识库未命中时联网检索 |
| P0 | 自适应教学风格 | 根据 is_weak_foundation 调整风格 |
| P1 | 多轮对话记忆 | 会话级别对话历史维护 |
| P1 | 学习报告 | 提问统计和主题分析 |
| P2 | Docker 容器化部署 | 一键部署 |
| P2 | 前端可视化 | React 对话界面 |

## 5. 非功能需求

| 类别 | 需求 |
|------|------|
| **性能** | 单次问答响应时间 < 10s（不含 LLM 推理时间） |
| **性能** | 向量检索延迟 < 500ms |
| **可用性** | API 返回结构化错误信息 |
| **可用性** | 前端加载时间 < 3s（首屏） |
| **安全** | API Key 通过环境变量注入，禁止硬编码 |
| **安全** | 输入验证，防止 SQL 注入 |
| **可维护性** | 模块化架构，Agent 可独立替换 |
| **可扩展性** | 支持新增 Agent 角色和工具
